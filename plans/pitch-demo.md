## 4. Demo con Turi

### Antes del viaje

1. **Pedido inicial.** "Me voy a Brasil, mi presupuesto es de 2.000 [INPUT: moneda]. Ayudame a conseguir vuelos y hoteles. Viajo con estas personas."
2. **Recomendaciones.** Turi propone vuelos y hoteles dentro del presupuesto.
3. **Invitación a los amigos.** Turi pide el email de cada acompañante para que tengan su billetera belo.
4. **Envío del referral.** Turi les manda el mail con el link de referido y el mismo mensaje por WhatsApp.

### Durante el viaje

5. **Tarjetas para el grupo.** "Haceme tres tarjetas: una para Marco, una para Francisco y una para Juan, con límite de USD 100 cada una."

### Después del viaje

6. **Reporte.** Turi arma el reporte de gastos del viaje.
7. **Saldos pendientes.** Turi les manda a cada uno un mensaje con lo que debe, si queda algún saldo pendiente.
