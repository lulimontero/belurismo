The globe uses the Latin American and Caribbean subset of Natural Earth's
1:110m Admin 0 countries, a public domain cartographic dataset.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/

Only country names, ISO-like administrative codes and geometry are retained.
No map, font, texture, or geocoding request is made to an external service at runtime.

The geographic silhouette is fitted to the visible sphere using a uniform
cartographic scale, with a smooth radial fit near the outer edge. This keeps
Latin America recognizable while giving it most of the front face. Terrain is
an artistic, low-amplitude relief following the Andes and Sierra Madre, not a
measured elevation model. Trip pins use the same projection as the land.
